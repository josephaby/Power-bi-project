 Data Analytics Project

 Overview

This project uses SQL Server and Power BI to explore sales and purchase
order data. The goal is to make key numbers easier to understand and
help identify sales trends and outstanding orders.

 Tools

-   SQL
-   Power BI

 What I Did

-   Imported and checked the project data.
-   Created SQL views for sales, payment types, transaction details,
    purchase orders, and organisation status.
-   Built a Power BI dashboard with sales KPIs, sales trends,
    payment-type analysis, transaction drill-through, and purchase order
    status.
-   Compared dashboard totals with SQL results to check accuracy.

 Dashboard Pages

-   Sales Analysis: total sales, quantity sold, sales trends, and
    payment types.
-   Sales Transaction Details: detailed transaction information with
    drill-through and a back button.
-   Purchase Order Analysis: ordered, received, and remaining
    quantities, with status highlighting.
